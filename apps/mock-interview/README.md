# AI Mock Interview Service (Forsati)

This directory is intended to host the upstream [modamaan/Ai-mock-Interview](https://github.com/modamaan/Ai-mock-Interview) project.

> Network cloning from GitHub is currently blocked in this environment. To populate this directory, run:
>
> ```bash
> git clone https://github.com/modamaan/Ai-mock-Interview apps/mock-interview
> ```
>
> Keep Forsati-specific configuration separate from upstream code.
