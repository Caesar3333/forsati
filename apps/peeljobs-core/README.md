# PeelJobs Core (Forsati marketplace)

This directory is reserved for the upstream [MicroPyramid/opensource-job-portal](https://github.com/MicroPyramid/opensource-job-portal) codebase.

> Network cloning from GitHub is currently blocked in this environment. To populate this directory, run the following from a networked environment:
>
> ```bash
> git clone https://github.com/MicroPyramid/opensource-job-portal apps/peeljobs-core
> ```
>
> Keep Forsati-specific additions isolated in separate Django apps per the contribution guidelines.
