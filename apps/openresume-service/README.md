# OpenResume Service (Forsati CV builder/parser)

This directory is intended to host the upstream [xitanggg/open-resume](https://github.com/xitanggg/open-resume) project (AGPL-3.0).

> Network cloning from GitHub is currently blocked in this environment. To populate this directory, run:
>
> ```bash
> git clone https://github.com/xitanggg/open-resume apps/openresume-service
> ```
>
> Keep Forsati-specific configuration separate to respect upstream code and licensing.
