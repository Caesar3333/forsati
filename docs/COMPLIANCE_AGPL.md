# OpenResume (AGPL-3.0) Compliance Plan

OpenResume is AGPL-3.0 licensed. Forsati must either:
- Operate OpenResume as a separate network service without proprietary modifications **or**
- Contribute modifications upstream / publish source for any derivative works, or
- Replace with a permissive alternative later.

Action items:
1. Keep OpenResume in its own container (`apps/openresume-service`) with clear network boundary.
2. Document any changes and publish corresponding source if deployed publicly.
3. Review dependency licenses for compatibility.
4. Consider swapping to a permissive resume parser if AGPL obligations become unacceptable.
