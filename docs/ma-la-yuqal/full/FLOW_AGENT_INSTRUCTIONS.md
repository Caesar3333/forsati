# تعليمات الوكيل في Google Flow (Agent instructions)

كل بطاقة: العنوان، ثم النص (انسخه كما هو). خلّي الصور المرفقة على البطاقات 1–3 مثل ما هي.
هذه التعليمات تنطبق على كل توليد، لذلك كل بطاقة تفرّق بين لقطات البودكاست (@me) ولقطات الموشن.

## 1. الصوت وحركة الفم — Voice & Mouth
```
Flow cannot lip-sync to an uploaded audio file. Do not try to lip-sync to an uploaded file. When @me speaks, animate natural mouth movement for the Arabic line written in the prompt, spoken in urban Jordanian (Ammani) colloquial dialect, with relaxed jaw, visible lips and teeth, and natural pauses between phrases. Never use an Egyptian accent. Never use a Gulf accent. Never use a Lebanese accent. Never use a Syrian accent. Never use Modern Standard Arabic. Facial expression follows a calm, reflective, sincere tone. No exaggerated gestures. The generated audio will be muted and replaced by the host's real recording. Never add music. Never add sound effects. Never add another voice.
```

## 2. الهوية — Identity Lock
```
Use the attached identity photos as the only source for the host's face. Keep exactly: short dark hair with receding temples; connected Van Dyke beard (moustache + goatee + soul patch) with a few grey hairs in the chin; a small dark mole above the LEFT corner of his upper lip, which appears on the viewer's RIGHT in a front shot. Never mirror the image. Never flip the image horizontally. The mole never moves. The mole never disappears. The mole never changes side. Do not beautify the face. Do not de-age the face. Do not slim the face. Do not change the skin tone. Mouth always visible. The microphone never covers the mouth. A hand never covers the mouth.
```

## 3. الحركة والأداء — Motion & Performance
```
Use the attached motion reference only for body language: seated at a desk, small natural head tilts, slow blinks, occasional light hand gestures below the chin, leaning slightly toward the microphone. Calm and grounded. No fast movements. No standing up. No walking. No looking around the room. Eyes mostly toward the listener slightly off-camera; brief looks into the lens only when the prompt asks.
```

## 4. الملابس والديكور — Wardrobe & Set
```
Unless a prompt says otherwise, the host wears a navy-blue unstructured wool blazer over a heather warm-grey crew-neck t-shirt. Studio: dark walnut vertical-slat wall, wooden shelves with a few books, a warm amber globe Edison lamp glowing in soft bokeh, light walnut desk, black dynamic microphone on a boom arm placed slightly to the side of his mouth. Keep wardrobe, set layout, mic position and lamp identical in every podcast shot.
```

## 5. الكاميرا والإضاءة — Camera & Light
```
Vertical 9:16, cinematic, photorealistic, 24fps feel, shallow depth of field. Moody low-key lighting: soft warm tungsten key from camera-left, gentle falloff into shadow, amber practical glow behind. Grade: teal-black shadows, warm amber highlights, slightly desaturated, light film grain. Camera moves are slow and subtle only (2–5% push-in, gentle pan, or locked-off). No whip pans. No camera shake. No fast zoom. No Dutch angles. No neon colours. No saturated colours.
```

## 6. الاستمرارية — Continuity
```
When a first frame is provided, continue exactly from it: same pose, framing, clothes, light and set, in the first second. No cut. No jump. No new angle. Keep the host in the same seat and position across all podcast shots so consecutive clips can be cut together invisibly.
```

## 7. لقطات الموشن — B-roll Metaphors
```
If a prompt does not mention @me, it is a B-roll metaphor shot: Do not insert the host. Do not insert any person unless the prompt describes one. Show silhouettes and hands only when the prompt asks. Same warm amber / teal-black palette and slow elegant motion as the podcast shots.
```

## 8. ممنوعات عامة — Output Rules
```
No on-screen text. No captions. No subtitles. No titles. No logos. No watermarks. No letters. No numbers. Arabic captions are added later in the edit. No split screens. No picture-in-picture. No extra people in podcast shots. Ignore filler quality words such as 8k or masterpiece.
```
