# تمبلت ستوري: «المشهد والعدّاد» (Stage + HUD)
**المعرّف:** `STAGE-HUD` · **الحالة:** مرجع بصري محفوظ، مش مصمّم بعد · **التاريخ:** 31/10/2026
**المرجع:** `REF_stage_hud_story.mp4` (50.8 ث، 720×1280، 30 إطار/ث، AAC 48k) + `REF_stage_hud_contact_sheet.png`.
**ملاحظة:** الفيديو مرجع لأسلوب فقط، لمحتوى شخص ثاني. ما بننسخ شخصياته ولا مشاهده ولا نصه.

## الفكرة بسطر
حكاية قصيرة بصوت واحد، كل جملة بمشهد مجسّم هادئ على مسرح غامق، مع لوحة صغيرة (HUD) بتعرض «حالة» بعدّاد أو مخطط، وكلمة وحدة مضيئة بكل جملة.

## عناصر الأسلوب (من المرجع)
| العنصر | الوصف |
|---|---|
| **الخلفية** | غامقة مع إضاءة مخروطية (سبوت) وتدرّج حار خفيف (أحمر/عنبري) من الأسفل |
| **الشخصية** | مجسّم أبيض بدون ملامح، بحجم كبير. مضيء = حاضر، غامق = غايب أو منسحب. هالة ذهبية حولها = حالة داخلية |
| **المشاهد** | ديوراما بسيطة وملوّنة بهدوء (حقل، محل، طاولة، حديقة، جبل). مشهد جديد كل 2–4 جمل |
| **النص** | صفّين: الجملة السابقة صغيرة باهتة فوق، والجملة الحالية كبيرة بيضاء تحتها، **كلمة وحدة ذهبية**. تظهر كلمة كلمة. خط عريض بتمديد حروف (كشيدة) |
| **اللوحة (HUD)** | بطاقة شفافة بحدود رفيعة: عنوان صغير، عدّاد أو شريط نسبة، وسم (chip)، رقم مشطوب، أو مخطط خطي بنقاط مسمّاة |
| **الحركة** | شريط يتعبّأ، رقم يعدّ، خط مخطط بيتحرك، جزيئات ذهبية، دخول ناعم للكلمات |
| **الصوت** | تعليق صوتي مسموع مع موسيقى خلفية، متوسط الصوت حوالي -17.8 dB |

## وين بيتماشى مع «ما لا يُقال»
- **الألوان:** غامق + ذهبي دافئ. قريب من لوحتنا (`#0B0D10`، عنبري `#E9B47A`، نحاسي `#B8835A`، عاجي `#EDE6D6`).
- **الخط:** نستخدم خطنا (عارف رقعة)، مش خط المرجع.
- **الصوت:** صوتك الحقيقي فقط.

## تعديلات لازمة عشان يشبه رسالتنا
1. **الإيقاع أهدى:** مشهد أطول، وكلمات أقل. هاد مش ستوري «تحفيزي».
2. **ما في أرقام مخترعة بالـHUD:** المرجع بيعرض نسب (16%، 99%). عندنا: عدّاد **رمزي** (مليء/فاضي)، أو بدون رقم، أو مكتوب «توضيح». ما بنعرض نسب كأنها إحصاء.
3. **المجسّم مش أنت:** شخصية مجرّدة. ما في وجه أو أفاتار (قرارك).
4. **ما في تفسير دوافع** ولا نصايح بالنص (البوصلة).
5. **سؤال مفتوح بالنهاية** بدل خاتمة «محفّزة».
6. **الحالة الداخلية** بتنعرض كوصف، مش تشخيص: هالة، إضاءة، شخص غامق. ما في كلمات سريرية.

## هيكل ستوري 30–45 ث (مقترح)
| الوقت | المحتوى |
|---|---|
| 0–3 | كلمة أو جملة افتتاح بنص كبير، سبوت على المسرح |
| 3–12 | موقف يومي بمشهد ديوراما + HUD رمزي |
| 12–25 | الانعطافة: المجسّم يتغيّر (إضاءة/هالة) |
| 25–35 | HUD يعرض «الكلفة» بشكل رمزي |
| 35–45 | سؤال مفتوح بنص كبير + «ما لا يُقال» |

## الإنتاج (مقترح، بدون تنفيذ)
- **المسار:** Remotion (عندنا) مع عناصر 2D/2.5D. مجسّم أبيض مبسّط بمجسمات React أو صور.
- **الخط:** عارف رقعة للنص الرئيسي، وIBM Plex Sans Arabic لعناوين اللوحة.
- **الصوت:** صوتك أنت (-14 LUFS) + موسيقى واطية.
- **الأبعاد:** 1080×1920 (المرجع 720×1280).
- **الجودة:** نص عربي مفحوص بأداة Harakah قبل الريندر (حروف متصلة، RTL).
