# سجل القصص والموافقات
**ما بنحفظ أكثر من اللازم. ما في أسماء حقيقية بالسجل. استخدم رمز.**

| الرمز | المصدر (A–E) | تاريخ الاستلام | الحساسية | الاستخدام الموافق عليه | طريقة الموافقة | آخر مراجعة | حالة | تاريخ الحذف المقرر |
|---|---|---|---|---|---|---|---|---|
| ST-001 | | | | | | | استلام / مراجعة / موافق / منشور / سُحب / محذوف | |

**الحالات:**
- استلام: لا استخدام.
- مراجعة: بانتظار موافقة.
- موافق: جاهز للمراجعة النهائية.
- منشور: لازم رابط بالمواد المنشورة.
- سُحب: إزالة من الصفحات.
- محذوف: تم حذف المصدر.
