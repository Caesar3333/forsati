# قائمة إخفاء الهوية
مبنية على S22 وS23 (ملخصات فقط). تتحدّث مع المراجعة القانونية.

## إزالة
- [ ] الأسماء (الشخص، الأهل، الأصدقاء، الشريك)
- [ ] مكان العمل، والجامعة، والمدرسة
- [ ] المنطقة والحي واسم الشارع
- [ ] أنواع السيارات والماركات المميزة
- [ ] التواريخ الدقيقة والأعياد المرتبطة بالحدث
- [ ] جمل أو كلمات مميزة بيعرفوها الناس القريبين

## تعميم
- [ ] الراتب ← «راتب متواضع»
- [ ] العمر ← «بالثلاثينات»
- [ ] عدد السنين ← «سنين طويلة»
- [ ] المهنة ← مجال عام أو بدونها
- [ ] المدينة ← «بالأردن» أو بدونها

## فحص التركيبات
- [ ] هل تجتمع تفاصيل بتحدد شخص واحد؟ (مثال: منطقة + مهنة + حدث)
- [ ] هل الحدث فريد ومعروف؟
- [ ] هل بيعرف الأقارب والأصدقاء من هو؟

## الصوت
- [ ] الصوت معرّف. هل في حاجة لتعديل أو قارئ ثاني؟
- [ ] اللهجة أو لازمة كلام مميزة؟

## قبل النشر
- [ ] صاحب القصة قرأ النسخة النهائية ووافق
- [ ] همّام وافق
- [ ] لا يوجد طرف ثالث مكشوف
- [ ] ملاحظة الدعم موجودة (للحساسية العالية)
